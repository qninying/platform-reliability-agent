# Capability catalog

Every capability Ellis has built, grouped by the job it does. Each one starts at autonomy R0 and its first
release is R2 (answers from records) unless the table says otherwise. Nothing here changes the live platform:
the R4 first releases act only on a sandbox copy, and the R1 one runs tests in a locked sandbox.

**Status** comes from the platform's own verification of this repository (`.colaberry/progress.json`):
*Verified* means the platform confirmed it from a commit that names the story. 24 more capabilities are planned in the platform's build plan for this domain
([`platform.json`](https://github.com/ColaberryIntern/ColaberryEnterprise_AI_LeadershipAccelerator/blob/44430870b/backend/src/services/agentDomain/capabilities/platform.json)).
