# Your capability path

One capability at a time, eight stages, and an artifact at every stage. This file is
REGENERATED by the platform on every document sync, so do not edit it: it reflects what is in
this repository, and the way to change it is to write the artifact.

## The checklist

**The platform did not supply a file list for this repository**, so every stage below reads `[?]` — not recorded. That is the platform not having looked, NOT a statement that you have not done the work.

A tick here means a FILE IS PRESENT at the path named. Nothing else can produce one: there is
no flag, no field and no API call that marks a stage done. If you did the work and the box is
empty, the artifact is missing or it is in the wrong place.

## What each stage is for

### Pick one from the list

Four candidates are on the table. Nobody has checked yet whether the product already does any of them.

**Produces** `artifacts/capability/{slug}/00-chosen.md`, and it counts when: It names the candidate chosen, which of the four sources it came from, and in one paragraph why this one before the other three.

### Write the scope sheet

The product cannot do this at all. Before anybody builds anything, write down what the thing is, who acts on its output, and what number would say it worked.

**Produces** `artifacts/capability/{slug}/10-scope-sheet.md`, and it counts when: It answers who acts on the output, what threshold decides success, and what the system already records that would produce that number.

### Waiting on the platform

The app has the machinery and no screen, or it half does this. Ali owes you a screen or a ruling. You are not blocked on yourself.

**Produces** `artifacts/capability/{slug}/20-what-is-missing.md`, and it counts when: It names the exact screen or ruling needed and the route it would live at, so the request is buildable rather than a complaint.

### Go and use what was built

The screen exists now. Use it until it does the job, or say plainly that it does not. Testing it is the work, not a formality before the work.

**Produces** `artifacts/capability/{slug}/30-tested-the-screen.md`, and it counts when: It records what was done in the screen, what worked, and what did not. A clean pass with nothing to report is a sign it was not really used.

### Do it by hand, in the app

The app already does this. Do it yourself first. Everything downstream is a judgement about work you have personally done.

**Produces** `artifacts/capability/{slug}/40-doing-it-by-hand.md`, and it counts when: It records the run: what was entered, what came out, how long it took, and what was annoying about it.

### Write the tool request

You have done it by hand and you know what it costs. Now ask for the tool, with the evidence rather than the idea.

**Produces** `artifacts/capability/{slug}/50-tool-request.md`, and it counts when: It carries the six field groups the tool request asks for, and the manual-today section cites the run recorded at the previous stage.

### Waiting on a decision

The request is filed and sitting with Ali. Nothing here is yours to move.

**Produces** `artifacts/capability/{slug}/60-filed.md`, and it counts when: It records the change request id, so the decision can be found later without searching.

### The agent does it, and you watch

Approved. The agent runs it and you check the output against what you produced by hand. This is the rung, and only this counts toward the gate.

**Produces** `artifacts/capability/{slug}/70-watched-runs.md`, and it counts when: It compares at least one agent run against the by-hand run, and states whether the threshold from the scope sheet was met.

## Two stages are not yours

- **Waiting on the platform** (`platform_owed`) — The app has the machinery and no screen, or it half does this. Ali owes you a screen or a ruling. You are not blocked on yourself.
- **Waiting on a decision** (`tool_requested`) — The request is filed and sitting with Ali. Nothing here is yours to move.

When you are at one of those, start another candidate. Four run in parallel for exactly this
reason, so nobody waits on a decision that is not theirs to make.

## You are never asked what you do by hand

You do not hold the job. Four candidates arrive from four places — your own research, the
person who actually holds the job, Ali, and suggestions scored against your rung — and you
choose one. The list says where each came from, because that is how much weight it deserves.
